# 《潮約之歌》

網頁遊戲，不用安裝任何東西，電腦、手機都能玩。

---

## 一、怎麼玩

**電腦**：雙擊 `game/index.html`，用瀏覽器（建議 Chrome / Edge / Safari 最新版）打開就能玩，不需要網路。

**手機**：要先把遊戲放到網站上（見第四節），用手機瀏覽器打開網址，再「加入主畫面」就能全螢幕遊玩。

### 操作

| 動作 | 電腦 | 手機 |
|---|---|---|
| 下一句 | 點擊畫面、空白鍵、Enter、滑鼠滾輪往下 | 點畫面 |
| 文字還在跑時 | 再點一次直接顯示整句 | 同左 |
| 快進（按住） | 按住 Ctrl | 按「快進」 |
| 選單 | Esc | 下方的快捷列 |
| 對話紀錄 | 滑鼠滾輪往上、↑、PageUp | 按「紀錄」 |
| 隱藏對話框 | 滑鼠右鍵、H | 按「隱藏」，再點一下畫面恢復 |
| 自動播放 | A | 按「自動」 |
| 選選項 | 點擊，或按 1、2、3… | 點選 |

快捷列：存檔、讀檔、紀錄、自動、快進、隱藏、設定、標題。

- **存檔**：3 頁 × 6 格手動存檔，另外每章開始和每次選擇前會自動存檔。存檔存在瀏覽器裡（同一台裝置、同一個瀏覽器才讀得到；清除瀏覽器資料會一起刪掉）。
- **繼續**：讀取最新的一筆存檔（包含自動存檔）。
- **CG 圖庫**：看過的 CG 會一直解鎖，重玩也保留。
- **人魚篇**：達成任一結局後解鎖；讀過主線第 N 章，人魚篇第 N 篇才會打開（00 需要讀過第一章）。
- **設定**：全螢幕、音樂／音效音量、介面音效、文字速度、自動播放速度、只快進已讀。
- **介面音效**：滑鼠滑過標題畫面與設定裡的按鈕、按下按鈕、點對話框翻下一句時的回饋音，可以在設定裡關掉；音量跟著「音效音量」。

> 瀏覽器規定要等玩家第一次點擊後才能出聲，所以標題畫面在點一下之後才會開始播音樂（介面音效也一樣）。

## 二、修改劇本後重新建置

劇本寫在 `script/` 資料夾，格式說明在 [`script/劇本格式.md`](script/劇本格式.md)。

改完劇本後：

1. **雙擊專案資料夾裡的 `build.bat`**（第一次使用要先安裝 [Node.js](https://nodejs.org/) 的 LTS 版本）。
2. 視窗顯示「建置完成」後，重新整理（或重新打開）`game/index.html`。

如果劇本有寫錯，視窗會顯示錯誤和位置，例如：

```
【錯誤】script/02_第二章_姐姐.md:21：【如果】指向不存在的標籤「2-1C」，是不是「2-1A」？
```

依照「檔名:行號」去修改即可。**有錯誤時不會更新遊戲**，遊戲會繼續使用上一次成功的版本。
「警告」不會擋住建置，但最好看一下（例如表情名稱不在角色設定.md 的清單裡）。

會檢查的項目：找不到的標籤（【跳至】、【如果】、選項）、重複的標籤、未知的【指令】、選項格式、條件與效果格式、結局代號、轉場名稱、表情名稱、沒設定過的旗標等。

會被打包的檔案：

- 主線：`script/01_*.md` ～ `script/99_*.md`，照檔名數字順序接起來。
- 人魚篇：`script/人魚篇/00_*.md`、`01_*.md`……
- `00_大綱.md`、`角色設定.md`、`劇本格式.md` 和其他檔案不會被打包。

### 進階（命令列）

```
node tools/build.js                      # 等同 build.bat
node tools/build.js --check              # 只檢查，不寫檔
node tools/build.js --list-assets        # 列出劇本用到的每個素材檔名，以及哪些已經放了
node tools/build.js --src <資料夾>        # 從別的資料夾讀劇本（例如測試用 tools/test-fixtures）
node tools/build.js --out <檔案>          # 輸出到別的檔案
```

## 三、替換佔位素材

現在沒有圖或音樂的地方，遊戲會自動用「佔位」：依背景名稱產生的漸層場景、角色剪影、CG 卡片、電腦合成的音樂與音效。
把真正的素材放進 `game/assets/` 對應的資料夾，**再執行一次 `build.bat`** 就會換上。每個資料夾裡都有 `README.txt` 說明命名方式。

| 類型 | 放在 | 檔名 |
|---|---|---|
| 背景 | `game/assets/bg/` | `<背景名稱>.jpg`（或 .png / .webp），例：`白鹽灣沙灘・黃昏.jpg` |
| 立繪 | `game/assets/sprites/` | `<角色>_<表情>.png`，例：`裴柱現_笑.png`；人魚等形態：`裴柱現_人魚_笑.png` |
| 主角頭像 | `game/assets/face/` | `孫承完_<表情>.png`，例：`孫承完_害羞.png` |
| CG | `game/assets/cg/` | `<編號>.jpg`，例：`02.jpg` |
| 音樂 | `game/assets/bgm/` | `<曲名>.mp3`，例：`白鹽灣日常.mp3`（「心動（安靜版）」找不到時會用 `心動.mp3`） |
| 音效 | `game/assets/se/` | `<名稱>.mp3`，例：`海浪.mp3`；介面音效可用 `介面滑過.mp3`、`介面點擊.mp3`、`介面翻頁.mp3` 取代 |
| 封面 | `game/assets/ui/` | `封面.jpg`（建議 1920×1080，主角放右半邊）；手機直拿可另放 `封面_直.jpg`（1080×1920） |

小提醒：

- 名稱要和劇本裡寫的**完全一樣**（中間點「・」也要一樣）。
- 立繪建議用透明背景 PNG；缺某個表情時會先用同角色的「普通」。
- 背景、CG 建議 1920×1080。音樂、音效建議用 .mp3（iPhone 不支援部分 .ogg）。
- 執行 `node tools/build.js --list-assets` 可以列出所有需要的檔名。

## 四、放到網站上用手機玩

整個 `game` 資料夾就是一個完整的網站，把它上傳到任何「靜態網站」服務即可，例如：

**最簡單：Netlify Drop**
1. 打開 <https://app.netlify.com/drop>（需要免費註冊）。
2. 把 `game` 資料夾整個拖進網頁。
3. 拿到網址後用手機打開。

**其他選擇**：GitHub Pages、Cloudflare Pages、Vercel 等，上傳 `game` 資料夾的內容即可。

> 每次修改劇本或素材後，要先執行 `build.bat`，再重新上傳 `game` 資料夾。

**加入主畫面（全螢幕遊玩）**

- **iPhone / iPad（Safari）**：按下方「分享」→「加入主畫面」，之後從主畫面的圖示開啟。iPhone 的 Safari 不支援網頁全螢幕按鈕，用這個方法才能全螢幕。
- **Android（Chrome）**：右上角選單 →「加入主畫面」或「安裝應用程式」。

從網站開啟並載入過一次後，遊戲會存一份在手機裡，沒有網路也能玩。
注意：網站版和電腦上雙擊打開的版本，存檔是**分開**的。

## 五、資料夾結構

```
build.bat                 雙擊重新建置劇本
README.md                 這份說明
script/                   劇本（.md）
tools/build.js            劇本 → game/data/script.js 的建置工具（零相依）
tools/make-icons.js       產生主畫面圖示 PNG（一般不需要再跑）
tools/test-fixtures/      測試用的小劇本（涵蓋所有指令、三種結局、人魚篇）
game/                     ← 整個上傳到網站就能玩
  index.html              遊戲入口
  css/                    樣式（故事書風格：羊皮紙、古典金框）
  css/ui/                 金框、緞帶、扇貝等裝飾圖（SVG）
  js/                     遊戲引擎
  data/script.js          建置產生的劇本資料（不要手動修改）
  assets/                 素材（背景、立繪、頭像、CG、音樂、音效、封面）
  manifest.webmanifest    加入主畫面用的設定
  sw.js                   網站版的離線快取
```

### 測試用劇本

```
node tools/build.js --src tools/test-fixtures --out game/data/test.js
```

再打開 `game/index.html?data=test`，就會改用測試劇本（存檔也和正式版分開）。
`tools/test-fixtures/errors/` 是故意寫錯的劇本，用來確認建置會報錯：`node tools/build.js --src tools/test-fixtures/errors --check`。

## 六、已知限制

- 存檔只存在目前的瀏覽器；換手機或換瀏覽器不會跟著走。瀏覽器禁止儲存時（例如某些無痕模式）會提示，存檔只保留到關閉頁面。
- 「加入主畫面」與離線快取只在網站版（https）有效；雙擊打開時不會啟用，這是瀏覽器的限制。
- 佔位音樂是即時合成的簡單旋律，正式音樂請放進 `game/assets/bgm/`。

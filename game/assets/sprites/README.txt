【立繪】放在這個資料夾

檔名：<角色>_<表情>.png（建議用透明背景的 PNG，也可用 .webp）
角色與表情要和劇本裡的「角色・表情」一致，表情清單見 script/角色設定.md。

例：劇本寫【立繪】裴柱現・笑　或　裴柱現・笑：「……」
　　→ 檔名 裴柱現_笑.png
沒寫表情 = 普通 → 裴柱現_普通.png

【形態】（例如人魚）：
劇本寫【形態】裴柱現・人魚 之後，會先找 裴柱現_人魚_<表情>.png，
找不到再找 裴柱現_人魚_普通.png，再找一般的 裴柱現_<表情>.png。

找不到某個表情時會改用該角色的「普通」；連「普通」都沒有時用佔位剪影。
主角（孫承完）沒有立繪，她的頭像請放在 face 資料夾。
放好之後重新執行專案資料夾裡的 build.bat。

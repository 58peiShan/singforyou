【音效】放在這個資料夾

檔名：<音效名稱>.mp3（也可以用 .ogg；iPhone 請用 .mp3）
音效名稱要和劇本【音效】後面寫的一致；一行寫多個用「、」分開。

例：劇本寫【音效】營火、海浪
　　→ 檔名 營火.mp3、海浪.mp3

沒有檔案時，海浪、水花、營火、雨、雷、腳步、開門、人群、玻璃碎裂、
刷和弦（吉他刷一小段）、撥和弦（吉他撥一個和弦讓它響著）
會用合成的佔位音效；其他名稱沒有檔案就不發出聲音。
放好之後重新執行專案資料夾裡的 build.bat。

劇本寫【音效】雨（室內）時，會拿「雨」的聲音，處理成隔著窗戶聽到的樣子
（變小聲、高音被玻璃擋掉）。想用專門錄的室內雨聲，就放一個 雨（室內）.mp3，會照原樣播。
注意：雙擊 index.html 開啟時，瀏覽器不允許處理音檔，「（室內）」只會變小聲；放到網站上才有隔窗效果。
（沒有音檔、用合成音效時，兩種開法都有隔窗效果。）

介面回饋音（設定裡的「介面音效」可以關掉）也可以換成自己的檔案：
　介面滑過.mp3　滑鼠滑過標題畫面、設定裡的按鈕
　介面點擊.mp3　按下按鈕、選擇選項
　介面翻頁.mp3　點對話框翻到下一句
沒有檔案時使用合成的音樂盒聲與翻書聲。

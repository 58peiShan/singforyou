# 劇本格式說明

遊戲引擎直接讀這些 .md 檔，執行 `node tools/build.js` 會把劇本轉成 `game/data/script.js`。

## 檔案

| 路徑 | 用途 |
|---|---|
| `script/NN_*.md`（NN = 01～99） | 主線，依檔名排序串起來，前一檔讀完自動接下一檔 |
| `script/人魚篇/NN_*.md` | 人魚篇。NN 對應主線章節，讀過主線第 NN 章才解鎖（00 需讀過第一章）；另需達成任一結局 |
| `script/00_大綱.md`、`角色設定.md`、`劇本格式.md` | 文件，不會被打包 |

## 文字

| 寫法 | 顯示 |
|---|---|
| `名字：「台詞」` | 對話，名字顯示在名牌 |
| `名字・表情：「台詞」` | 對話，同時把該角色立繪（孫承完則是頭像）換成該表情 |
| `（……）` 整行括號 | 內心話（不同字色） |
| 其他文字 | 旁白 |
| `#`、`---`、空行、`>` 開頭、`<!-- -->` | `# 標題` 會顯示章節標題卡（「開場」除外），其餘忽略 |
| `## 1-1　標題` | 標籤，id 是第一個空白前的部分（`1-1`），全域唯一 |

## 指令（行首【】）

| 指令 | 說明 |
|---|---|
| `【背景】名稱` | 交叉淡入切換背景，立繪保留 |
| `【立繪】角色・表情、角色` | 顯示／更新立繪，沒寫表情 = 普通；未列出的角色保持原狀；自動排位（1 人置中、2 人左右、3 人左中右） |
| `【形態】角色・形態` ／ `【形態】角色` | 切換該角色的立繪圖組（例：`【形態】裴柱現・人魚`）；只寫角色或寫 `・人類` = 回到預設。不會讓角色登場或退場，在場時直接換圖 |
| `【退場】角色` ／ `【退場】全部` | 立繪淡出 |
| `【CG】編號 名稱` | 顯示 CG，並在圖庫解鎖 |
| `【CG結束】` | 收起 CG |
| `【音樂】名稱` ／ `停` ／ `淡出` | 背景音樂 |
| `【音效】名稱、名稱` | 音效 |
| `【轉場】淡出` ／ `淡入` ／ `閃白` | 淡出到黑、從黑淡入、白光一閃 |
| `【震動】` | 畫面震動 |
| `【數值】心動 +1` | 改數值（心動、信任、採息，初始 0） |
| `【旗標】名稱` | 設定旗標 |
| `【如果】條件 → 標籤` | 條件成立就跳到標籤，否則往下讀 |
| `【跳至】標籤` | 跳到標籤 |
| `【選擇①】` | 下面連續的 `A. 文字 →（效果）→ 標籤` 行是選項，效果可省略 |
| `【第一章　完】`（任何 `【…完】`） | 章節結束卡，記錄「讀過此章」 |
| `【結局】代號「名稱」` | 代號：伴侶／朋友／BAD。顯示結局卡、記錄結局、回標題 |

### 條件與效果
- 條件：`心動 >= 8 且 採息 == 0 且 旗標:坦白`，可用 `且`、`或`、`>= <= > < == !=`，旗標前加 `非` 表示沒有該旗標（`非旗標:坦白`）。
- 效果：`（心動 +1、信任 -1、旗標:知道名字）`，`-` 和 `−` 都可以。

## 素材命名

放進 `game/assets/` 對應資料夾，重新執行 build 即可替換佔位圖。找不到檔案時引擎用佔位圖／佔位音樂。

| 類型 | 路徑 |
|---|---|
| 背景 | `bg/<背景名稱>.jpg` / `.png` / `.webp` |
| 立繪 | `sprites/<角色>_<表情>.png`；設了【形態】時先找 `sprites/<角色>_<形態>_<表情>.png`，再找 `<角色>_<形態>_普通`，再找一般立繪 |
| 孫承完頭像 | `face/孫承完_<表情>.png` |
| CG | `cg/<編號>.jpg` / `.png` / `.webp` |
| 音樂 | `bgm/<名稱>.mp3` / `.ogg` |
| 音效 | `se/<名稱>.mp3` / `.ogg` |
